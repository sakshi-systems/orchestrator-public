# Courier reference

The [courier](../features/courier.md) governs behaviour. This page holds its values.

## Courier delivery

Both native sends make one standard blocking subprocess attempt, bounded by a timeout of **30 seconds**, with null stdin and stdout/stderr retained in the caller's file-backed output.

Native argument/tool/model policy belongs to the recipient's section **How a head of this runtime is reached**: [Codex](https://github.com/sakshi-systems/skills-public/blob/main/src/skills/architect-runtime-codex/SKILL.md#how-a-head-of-this-runtime-is-reached) and [Claude](https://github.com/sakshi-systems/skills-public/blob/main/src/skills/architect-runtime-claude/SKILL.md#how-a-head-of-this-runtime-is-reached).
